# Проверка проекта iOS — 18 октября 2026

В Linux прошли **9 тестов ядра, 0 ошибок**, и отдельная обратная проверка Java/Tink.

## Что выполнено

- Swift 6.0.3 для Ubuntu 24.04 получен с официального `download.swift.org`.
  Подпись архива проверена официальным ключом Swift 6.x.
- Собрано настоящее ядро `Core/`, включая HPKE/Ed25519 и Firebase REST-клиент.
  В Linux используется официальный Swift Crypto 3.12.3; точные Git-ревизии
  Swift Crypto и Swift ASN.1 закреплены в `Package.resolved`.
- В Linux среда несовместима с новым драйвером Swift 6.0.3 при сборе статистики
  процессов. Использован штатный старый драйвер `SWIFT_USE_OLD_DRIVER=1` и
  `-Xswiftc -disallow-use-new-driver`. Обёртка SwiftPM также аварийно завершалась
  при учёте дочерних процессов через `/proc`; собранный XCTest запускается
  напрямую. Исходный код криптографии не менялся для ослабления проверок.
- Тесты ядра проверяют расшифрование Android-конверта в Swift, точную сериализацию
  публичных Tink-ключей, подмену всех подписанных полей, неверного отправителя,
  неверного получателя, секретные/повторяющиеся protobuf-поля, base64url,
  UTF-8, лимит 12 000 байт, случайность шифрования и unsigned 32-bit ID ключей.
- Проверены сохранение структуры истории/личности, устранение дублей,
  счётчик непрочитанного, закрытый выбор адресов сервера и приглашения другого
  проекта. Отдельный async XCTest успешно проверил сериализацию 20 параллельных
  сетевых действий через участки с `await`.
- **Android → Swift:** конверт создал тот же `SecureCrypto.java` с Tink 1.23.0,
  который используется в APK. Swift расшифровал и проверил его подпись.
- **Swift → Android:** настоящий Swift-код создал ответ; JVM запустила
  Android `SecureCrypto.open` и успешно проверила подпись/расшифровала текст.
  Проверка включает русский текст, переносы строк, эмодзи и знаки HTML как текст.
- Firebase REST-клиент с URLSession и запретом перенаправлений скомпилирован.
  Дополнительно проверены типы `MessengerStore` в Linux с минимальными
  заглушками Combine/DeviceVault; это проверка типов, **не** тест iOS-хранилища.
- Все Swift-файлы разобраны независимым синтаксическим парсером.
  Проект Xcode разобран как OpenStep plist; пути файлов, XML/plist, общая схема
  и соответствие Firebase-конфигурации Android проверены.
- Исходный APK 0.4 не пересобирался и не изменялся; SHA-256:
  `f6d9d457f7f793ce1d9dbb3c51777d3a1cfa14082325bd3113321dce2864a1bb`.

## Как повторить проверку на Mac

```sh
swift test
./build-ios.sh simulator
```

Для повторной двусторонней проверки с Android сначала задать
`MICROCHAT_INTEROP_OUTPUT` при запуске `swift test`. Этот файл проверяется Java-тестом
`tests/IOSInteropTest.java verify <fixture.json> <swift-reply.json>` из полного
архива исходников. Fixture содержит публичные тестовые приватные ключи и никогда
не включается в ресурсы приложения MicroChat.
